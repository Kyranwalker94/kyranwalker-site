kyranwalker.com Rebuild 💻

This site. A full rebuild in 2026, moving off a dated WordPress install on Bluehost and into a hand-built static site that doubles as a virtual CV and a portfolio.

The project

The old version of this site had been running on WordPress through Bluehost for years, built up in layers of plugins and page builder edits until it was slow to load and painful to change. Every small update meant wading through an admin panel I didn't fully trust, and the hosting bill kept creeping up on renewal.

In 2026 I pulled it all down and started again from scratch. The site now works as a proper virtual CV and portfolio, somewhere I can point anyone to and have it reflect exactly what I'm doing, not just for job applications, but for whatever self-employed work is the current focus. It's been through a few different versions of "what I do" this year alone, bookkeeping, fibre contracting, home and property services, and each time the site just gets updated rather than rebuilt.

Why rebuild

  • WordPress and its plugins had gotten slow and increasingly annoying to maintain
  • Wanted full control over design and markup instead of fighting a theme
  • Needed something that could flex quickly between CV mode and services mode
  • Bluehost renewals kept creeping up for hosting a handful of static pages
  • Wanted to actually understand and own every part of the site, not just the content

The stack

Plain HTML, CSS, and vanilla JavaScript, no framework, no build step, no bundler. Each page is written by hand, which keeps things simple and means there's nothing to break between dependency updates because there aren't any.

  • A homepage, profile/CV page, and a filterable projects index
  • A library of quote and estimate tools for different side services, fence, van, bookkeeping, tech support, and more
  • Standalone project pages for things I've built or worked on, this one included
  • A life timeline page pulling from a single shared data file
  • A separate mini-site for a family dinner booking calendar

Hosting & deployment

The site moved off Bluehost entirely and is now hosted on Cloudflare, connected straight to the GitHub repo. There's no FTP, no manual uploads, and no renewal invoice creeping up every year, I push a commit to the main branch and Cloudflare builds and deploys the new version within moments. A couple of small bits of backend logic, like a leaderboard and some contact form handling, run as lightweight serverless functions rather than needing a full server anywhere.

How it's built

Most of the code is hand-written, I like knowing exactly what every line of a page does, and vanilla HTML/CSS/JS is simple enough that there's rarely a good reason not to write it directly. For the fiddlier bits, chasing down a layout quirk, wiring up a Cloudflare function, or figuring out why something wasn't behaving as expected, I've used Claude as a sounding board along the way. It's a faster version of searching for the answer yourself when you're stuck on something specific, not a replacement for actually knowing the codebase.
